# Wednesday 25 November 2026 — World Frontpage

A hyper-dense one-image world news sheet for Wednesday 25 November 2026: 35 dated stories, 9 regions, 14 fields. Three illustrated leads (the Asian chip sell-off, the Hormuz tanker blasts, Pakistan's first astronaut), 15 mini story cards, a dot-matrix world map with story locations, a markets snapshot, and a 16-entry UTC timeline.

Run `python3 main.py` with Pillow installed to render the 1024 × 1024 poster to `/output/entry.png` (set `OUT_DIR` to change the destination). Every run writes identical PNG bytes.
